# Edvid Studio — primeira versão local
Goal: aplicativo Mac próprio conectado ao motor compartilhado, com projetos persistentes e fila local.
Architecture: shell nativo Swift/WebKit (sem instalar outro Chromium), serviço Python local com token aleatório, editor de preview existente. Esta primeira distribuição depende da instalação compartilhada; ainda não é pacote independente para outros computadores.
Tech stack: AppKit/WebKit, Python standard library, FFmpeg, preview existente.
Spec: EDVID-STUDIO-PROPOSTA.md aprovada pelo usuário.
Constraints: preservar uv.lock e trabalho do Claude; nenhum código comercial copiado; sem integração externa fictícia; mídia original intacta; fila nunca repete operação automaticamente após interrupção.

## Task 1 — Serviço, projetos e fila
Files: helpers/studio_server.py, assets/studio/{index.html,app.js,style.css}, tests/test_studio.py.
Interface: python helpers/studio_server.py --port 0 --data-dir PATH; stdout primeira linha JSON {url: "http://127.0.0.1:PORT/?token=..."}. Serviço somente loopback, sessão autenticada por cookie após bootstrap token; validar Origin em mutações. Projetos registrados por caminho, criar/abrir diretório; oferecer preview existente via rota autenticada /editor/<id>/ encaminhando Handler existente com paths funcionais. Persistência atômica; fila serial persistida, tarefa local probe (ffprobe) e proxy (FFmpeg, arquivo separado), cancelamento subprocesso, execução anterior interrompida marcada interrupted. UI em português: biblioteca, caminho/importação por texto, projeto selecionado, preview/editor, fila e diagnóstico. Sem execução de comandos arbitrários. Testes reais de autenticação, persistência, path safety e fila/cancelamento.

## Task 2 — Aplicativo Mac e documentação
